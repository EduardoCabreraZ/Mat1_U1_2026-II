Forma logarítmica
💡 Libro (p. 148): logb(x) = y  ⟺  x = by. El logaritmo pregunta: «¿a qué exponente debo elevar la base b para obtener x?».
a) logb(A·B) = logbA + logbB
b) logb(A/B) = logbA − logbB
c) logb(An) = n·logbA
d) Cambio de base: logbA = ln A / ln b
e) logb(1) = 0
f) logb(b) = 1
💡 Mueve los deslizadores: ambos lados de cada igualdad siempre coinciden. Notación del libro: log = log10 y ln = loge.
